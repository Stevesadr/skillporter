### Decisions taken this phase

  Official docs only state that `name` + `description` are required and give their rules;
  they never say whether `license`/`compatibility`/`metadata`/`allowed-tools` are accepted.
  Those four are `status: unknown` + `dropReason`, so they are dropped and reported rather
  than emitted on a guess. Three searches found only blogs; the 1c claim that the upload
  form "hard-errors on any other key" was unverified and has been corrected in the README.

  exactly the case where `planBody`'s `shouldTransform` is false, so the body is copied
  byte-for-byte and nothing is new. `error` still applies when a verified source did not
  execute; `warning` only when the source behaviour is unknown.

  manifest) is not a tautology in its test. Not published, not tagged.
- **`@skillporter/core: "*"` left as-is** in the CLI dependency. Changing it needs a real
  `npm install` to resync the lock, and the sandbox cannot delete `node_modules`. Listed in

### Bugs found and fixed (all with tests)

1. `agents/` and `schema/` lived only at the repo root, so an installed tarball could not
   load a single profile. Fixed with `scripts/sync-package-data.mjs` on `prepack`, plus
   `files: [dist, agents, schema]`. Found by the new package check.
2. `packages/cli` had no `files`, so `.gitignore`'d `dist/` would have been excluded from
   its tarball. Same check.
3. `unzipSync` inflated every entry before the size limits applied: a zip bomb bypassed
   `maxTotalBytes`. Limits are now read from the central directory via fflate's `filter`,
   before decompression.
4. `--version` printed a hard-coded `0.0.0`.
5. Block-scalar/quoted frontmatter was re-spelled (`description: |` lost its indentation
   and made the whole frontmatter unparseable while still reporting `preserved`).

### Gotchas worth remembering

- `npm pack --json` puts anything written to stdout into its JSON report, so a `prepack`
  hook must stay silent on stdout. Use `console.error` behind an env flag.
- `---` inside a YAML string starts a new document rather than closing one; a round-trip
  assertion must parse the emitted field alone, not `---\n${field}\n---\n`.
- A test whose input and expectation both come from the same constant (e.g. `--version`
  against a manifest that is also `0.0.0`) passes with or without the fix. Bump the data or
  drop the assertion.
